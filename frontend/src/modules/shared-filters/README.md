# Shared Filters

Base mínima para filtros reutilizáveis entre grids e dashboards.

## Incluído

- `SharedSearchFilter`
- `SharedSelectFilter`
- `SharedMultiSelectFilter`
- `SharedPeriodFilter`
- `useSharedFiltersState`

## Regra atual

O módulo foi criado como infraestrutura, mas ainda não foi adotado em telas reais.
Isso evita abstração prematura e permite adoção incremental quando houver reaproveitamento concreto.
