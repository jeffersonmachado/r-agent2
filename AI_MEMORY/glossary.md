# Glossary

- RAP: Results Autonomous Platform.
- AI_MEMORY: official operational memory for agents and automations.
- QA Waves: governed scenario/journey validation waves.
- QA Mesh: execution mesh that consolidates scenarios, evidence, metrics and GO/NO_GO.
- Replay: deterministic RPA/runtime evidence artifact.
- Self-Proving: governance proof chain derived from reports and artifacts.
- Runtime Governance: classification of REAL_OK, SYNTHETIC_OK, REAL_FAILED_FALLBACK_USED or BLOCKED.
- RAP Workspace: customer/operation 360 surface.
- GO_FINAL_HARDENED: final release state allowed only after all release, QA, replay, package and governance gates are green.
- NO_GO: blocking decision that prevents release promotion.
