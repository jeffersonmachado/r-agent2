## Replay Integrity Model

Each replay artifact now persists:

```json
{
  "replayHash": "sha256",
  "replayChecksum": "sha256:<hash>",
  "governanceSignature": "hmac-sha256:<signature>",
  "integrity": {
    "algorithm": "sha256+hmac-sha256",
    "signatureAlgorithm": "hmac-sha256",
    "keyId": "non-secret key identifier"
  },
  "generatedAt": "ISO-8601",
  "tenantId": "isolated tenant id",
  "environment": "prod-like execution metadata",
  "smokeExecutionId": "deterministic smoke execution id"
}
```

Integrity validation verifies:

- replay hash exists and matches the canonical replay payload
- replay checksum exists and matches the hash
- governance signature exists and matches the replay/governance payload
- legacy unkeyed `gov-sha256` values are rejected
- replay tampering is detected as `NO_GO`
- checksum, hash, or signature corruption is detected as `NO_GO`

Retention policy:

- `qa-waves-prod-like-90d`
- artifacts are marked immutable through the persisted `integrity.immutable = true`
- deterministic export is the stable sorted replay payload used for hashing
