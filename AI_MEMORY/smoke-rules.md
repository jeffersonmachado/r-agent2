# Smoke Rules

Use the smallest smoke set that proves the changed surface, then broaden to release gates when governance or shared runtime changed.

Known smoke entrypoints:

- `scripts/smoke/frontend-smoke.sh`
- `scripts/smoke/qa-waves-operational-final-smoke.js`
- `scripts/smoke/qa-waves-enterprise-proof-smoke.js`
- `scripts/test-rpa-replays-scale-smoke.js`
- `scripts/workspace-core-smoke.js`
- `scripts/test-pbx-call-events-runtime-smoke.js`
- `scripts/test-whatsapp-qr-smoke.js`
- `scripts/test-inbox-runtime-smoke.js`
- `scripts/test-physical-queue-smoke.js`

Evidence must record command, date, environment, runtime classification, result and artifact paths.
